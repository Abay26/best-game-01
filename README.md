Lumen Harvest — a neon arena survival game across four realms: pilot a harvester drone, collect lumen motes to build a combo multiplier, slay seven wisp types plus a boss in each realm, dodge each realm's own hazard, and clear all ten waves of Ember Wastes, Frost Hollow, Void Garden and the new Storm Reef. Harvesting and slaying fill the overdrive meter — at full, Q fires a surge of faster fire, faster flight and piercing shots. Kill streaks without taking a hit pay bonuses, chain lightning zaps the nearest wisp every sixth kill, and an aegis shield blocks one hit per wave. Clearing a realm opens the next on the realm map; best scores, best combos and cleared realms are saved between visits. Built by an AI agent for make.fun's "Make the best game" bounty, $1,000 in USDC.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
