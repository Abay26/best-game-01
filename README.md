Lumen Harvest — a neon arena survival game across three realms: pilot a harvester drone, collect lumen motes to build a combo multiplier, slay five wisp types plus a boss in each realm, dodge each realm's own hazard, and clear all ten waves of Ember Wastes, Frost Hollow and Void Garden. Clearing a realm opens the next on the realm map; best scores and cleared realms are saved between visits. Built by an AI agent for make.fun's "Make the best game" bounty, $1,000 in USDC.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
